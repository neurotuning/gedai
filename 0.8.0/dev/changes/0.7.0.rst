Version 0.7.0
=============

Enhancements
------------

- Respect MNE bad-channel annotations (``info['bads']``) via ``on_bad_channel`` (``"exclude"`` default or ``"ignore"``) across :class:`~gedai.gedai.Gedai`, :class:`~gedai.gedai.MultibandGedai`, and :class:`~gedai.gedai.AdaptiveMultibandGedai` (:issue:`182`, `Tomas Ros`_).
- Add MATLAB GEDAI-inspired automatic two-pass bad-channel detection via ``bad_channel_threshold`` (``None``, ``"auto"`` for ``0.95``, or positive float), detecting flat channels in a pre-pass and high-ENOVA channels in Pass 1 before refitting Pass 2 on good channels, and exposing ``bad_channels_``, ``detected_bad_channels_``, ``flat_channels_``, ``noisy_channels_``, and ``enova_per_channel_`` (:issue:`182`, `Tomas Ros`_).
- Add optional ``interpolate_bads`` parameter on ``transform_raw`` and ``transform_epochs`` to reconstruct excluded bad channels using MNE spherical spline interpolation and re-apply EEG average referencing (:issue:`182`, `Tomas Ros`_).
- Revise default ``wavelet_low_cutoff`` to ``0.1`` Hz with a single Haar wavelet high-pass pre-filter before broadband GED, anchoring spectral MRA decomposition at ``0.5`` Hz while retaining and spatially cleaning the ``0.1-0.5`` Hz scaling band, and supporting ``wavelet_low_cutoff=0.0`` / ``None`` (mean centering only, zero acausal pre-stimulus leakage) (`Tomas Ros`_).
- Make fitting and transformation invariant to uniform input amplitude rescaling (e.g., Volts versus microvolts) across all estimators, SENSAI methods (``"optimize"`` and ``"gridsearch"``), and NumPy/PyTorch backends by trace-matching the reference covariance to the data covariance and replacing fixed absolute numerical floors with scale-relative tolerances (:issue:`185`, `Tomas Ros`_).

Bugs
----

- Standardize ``fit_metrics_``, ``metrics_``, and ``_info`` initialization (``None`` before fitting/transforming), population, and docstrings across :class:`~gedai.gedai.Gedai`, :class:`~gedai.gedai.MultibandGedai`, and :class:`~gedai.gedai.AdaptiveMultibandGedai`, fixing ``AttributeError`` in ``Gedai.plot_sensai`` (:issue:`183`, `Tomas Ros`_).
- Fix amplitude-scale sensitivity in ``fit_epochs``, ``transform_epochs``, ``fit_raw``, ``transform_raw``, ENOVA, and SENSAI scoring when inputs are scaled in microvolts rather than Volts (:issue:`185`, `Tomas Ros`_).
- Fix bad-channel handling and reference covariance picking when MNE ``info['bads']`` channels are present in input ``Raw`` or ``Epochs`` objects (:issue:`182`, `Tomas Ros`_).

API and behavior changes
------------------------

- Channels listed in ``info['bads']`` are now excluded by default during fitting (``on_bad_channel="exclude"``) and raise a ``ValueError`` at transform time if a fitted channel is marked bad; pass ``on_bad_channel="ignore"`` to retain legacy behavior (:issue:`182`).
- Default ``wavelet_low_cutoff`` in :class:`~gedai.gedai.MultibandGedai` and :class:`~gedai.gedai.AdaptiveMultibandGedai` changed from ``0.5`` Hz to ``0.1`` Hz; subbands are only zeroed out for cutoffs ``>= 0.5`` Hz.
- All estimators now consistently initialize ``fit_metrics_``, ``metrics_``, and ``_info`` to ``None`` in ``__init__``, storing fit-time metrics in ``fit_metrics_`` and transform-time metrics in ``metrics_`` (:issue:`183`).
