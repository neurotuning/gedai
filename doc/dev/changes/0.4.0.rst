Version 0.4.0
=============

Enhancements
------------

- Add comprehensive MEG data support for Magnetometers, Gradiometers, and Optically Pumped Magnetometers (OPM) (:pr:`150` by `Tomas Ros`_ and `Victor Férat`_).
- Implement MEG-aware SENSAI scoring using singular value projection and adaptive artifact spectrum prescanning (:pr:`150` by `Tomas Ros`_ and `Victor Férat`_).
- Add support for passing MNE :class:`~mne.Forward` models directly as ``reference_cov`` in :class:`~gedai.gedai.Gedai`, :class:`~gedai.gedai.MultibandGedai`, and :class:`~gedai.gedai.AdaptiveMultibandGedai` (:pr:`150` by `Tomas Ros`_ and `Victor Férat`_).
- Add :func:`~gedai.covariance.covariance.compute_covariance_from_forward` to compute cortical reference covariance matrices from forward solutions (:pr:`150` by `Tomas Ros`_ and `Victor Férat`_).
- Add ``n_pc`` parameter to :class:`~gedai.gedai.MultibandGedai` and :class:`~gedai.gedai.AdaptiveMultibandGedai` (:pr:`150` by `Tomas Ros`_ and `Victor Férat`_).
- Increase SENSAI epoch cap to 500 epochs for improved optimization convergence (:pr:`150` by `Tomas Ros`_).
- Set default verbosity level to ``INFO`` to provide informative progress logging out of the box (:pr:`150` by `Tomas Ros`_).
- Tighten wavelet band optimization bounds to guard against overcleaning (:pr:`150` by `Tomas Ros`_).

Bugs
----

- Fix reference covariance channel picking and case-insensitive matching in :func:`~gedai.covariance.covariance._pick_cov` (:pr:`150` by `Tomas Ros`_).
- Ensure average reference is never applied to MEG sensor arrays (:pr:`150` by `Tomas Ros`_ and `Victor Férat`_).
- Preserve raw metadata and sensor coordinates across transformation (:pr:`150` by `Tomas Ros`_ and `Victor Férat`_).

API and behavior changes
------------------------

- Automatic signal type detection (:func:`~gedai.gedai._utils._detect_signal_type`) from channel types.
- Default ``verbose=None`` now defaults to ``logging.INFO`` level.
