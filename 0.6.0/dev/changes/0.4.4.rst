Version 0.4.4
=============

Bugs
----

- Restrict reference covariance trace scaling strictly to MEG data (``signal_type == "meg"``), avoiding unwarranted down-scaling of calibrated OpenMEEG physical EEG leadfields and restoring high-fidelity artifact component rejection in EEG denoising (`Tomas Ros`_).
- Align noise and signal subspace similarity computation in SEnSAI (``_sensai_score_loop``) to the exact 3x3 determinant matching MATLAB EEGLAB GEDAI, improving artifact detection sensitivity across multi-component sensor subspaces (`Tomas Ros`_).
